# ZION | Landing Page Institucional

Landing page institucional desenvolvida para a **ZION**, empresa prestadora de serviços de manutenção e soluções técnicas para ambientes residenciais, comerciais e empresariais.

O projeto foi construído com **HTML5, CSS3 e JavaScript**, com foco em apresentar a empresa, comunicar seus serviços e facilitar o contato de potenciais clientes.

## Sobre a ZION

A ZION atua com serviços de:

- Hidráulica e elétrica;
- Segurança eletrônica;
- Ar-condicionado;
- Serralheria;
- Pintura;
- Manutenção predial.

A empresa atende públicos de diferentes portes, incluindo condomínios, comércios, microempreendedores individuais (MEIs) e outras empresas.

## Objetivo do projeto

Criar uma presença digital institucional que apresente a ZION de maneira clara e organizada, explique como funciona a contratação de serviços e ofereça caminhos acessíveis para solicitar uma visita técnica.

## Funcionalidades

- **Apresentação institucional:** seção dedicada à empresa e às suas áreas de atuação.
- **Etapas de atendimento:** explicação visual do processo, desde a solicitação de visita técnica até o agendamento do serviço e o feedback.
- **Navegação por seções:** links para acessar diferentes partes da página.
- **Canais de contato:** atalhos para WhatsApp, e-mail e telefone.
- **Interações com JavaScript:** comportamentos de navegação e interação da interface.

## Processo de atendimento apresentado na página

1. **Solicitação de visita técnica:** o cliente entra em contato para avaliação e levantamento das medidas necessárias.
2. **Medição e orçamento:** as informações são encaminhadas aos profissionais parceiros, que avaliam a proposta de serviço.
3. **Agendamento e feedback:** após a definição do atendimento, o serviço é agendado e há acompanhamento do retorno do cliente.

## Executando localmente

Este é um projeto de front-end desenvolvido com tecnologias web nativas, sem necessidade de instalar dependências para visualizar suas páginas estáticas.

1. Clone o repositório:

   ```bash
   git clone https://github.com/nicolesmatos/zion.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd zion
   ```

3. Abra o arquivo HTML principal no navegador. Também é possível utilizar a extensão **Live Server** no Visual Studio Code durante o desenvolvimento.
